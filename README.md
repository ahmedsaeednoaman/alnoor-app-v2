## Application review and future printing boundary

Interactive financial review (`/accounts/review`) is a responsive card-based workflow. The operational browser (`/operations`) has its own presentation. Neither application view is the printable report renderer.

A future Print Center should use dedicated light-background A4 table layouts with day/week/month/custom periods:

- Lithotripsy: cases, doctors, hospitals, procedures, and permission/template-controlled operational or financial columns.
- Endoscopy: doctor, case, hospital, devices, employee, and applicable financial columns.
- Contract: hospital, case, unified/reference number, contract entity, procedure/device, value, and compatibility with the existing monthly Contract report.

Print layouts must remain separate from application cards and must not inherit application dark-mode surfaces.
